# Litematica Folder Button Mod

A simple Fabric mod for Minecraft 26.2 that adds a folder button to the Litematica menu, making it easy to open your schematics folder directly from the game.

## Features

- 📁 Adds a "Schematics" folder button to Litematica main screen
- Opens your schematics folder with one click
- Automatically creates the schematics folder if it doesn't exist
- Works on Windows, macOS, and Linux
- Lightweight and non-intrusive

## Requirements

- Minecraft 26.2
- Litematica mod 26.2
- Fabric Loader 0.19.3+
- Java 21+

## Installation

1. Download the latest JAR from [Releases](../../releases)
2. Copy to your `.minecraft/mods/` folder
3. Launch Minecraft with Fabric
4. Press M to open Litematica menu
5. Click "📁 Schematics" button at top right!

## How It Works

The mod hooks into Litematica's screen events and adds a button to the main menu. Clicking it opens your schematics folder in the default file manager.
